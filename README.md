# 数学建模共享参考

本仓库用于整理可公开共享的数学建模学习资料。

## 使用说明

- 资料仅供学习、研究与方法参考；请遵守原作品的著作权和竞赛规则。
- 参赛时请独立完成建模、分析、写作与代码；禁止照搬、代写或将他人论文作为自己的作品提交。
- 发现版权、隐私或内容问题，请通过仓库 Issue 联系维护者处理。
